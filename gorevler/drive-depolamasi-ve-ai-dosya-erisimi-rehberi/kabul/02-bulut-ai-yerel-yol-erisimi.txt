# Kabul 02 — Bu bulut konteynerinde Windows/Drive yolları açılabiliyor mu?
# Tarih: 2026-10-03T13:44:11Z  Makine: Linux 6.18.44-fc-v64
# KAPSAM (bu kanıt NEYİ gösterir / göstermez):
#  Gösterir: Bu tek Linux bulut konteynerinde (Claude Code cloud oturumu) bu üç Windows yolu yok ve
#            DriveFS/SMB bağlama noktası görünmüyor. Yani bu ajana yalnız yol metni vermek dosyayı getirmedi.
#  Göstermez: Tüm web AI'ların veya tüm yerel ajanların erişimi hakkında mutlak hüküm. Erişim şu koşullara
#            bağlıdır ve burada ayrı ayrı test EDİLMEDİ: (a) dosya sistemi o makineye bağlı mı (mount),
#            (b) aracın izin/sandbox ayarı klasörü kapsıyor mu, (c) dosya sohbete yüklendi mi,
#            (d) servisin Drive bağlayıcısı OAuth ile bağlı mı, (e) PC'de çalışan bir köprü/ajan var mı.
#  Ayrıca Linux 'ls' Windows ters eğik çizgili yolu tek bir dosya adı olarak arar; bu, "yol bu
#  makinede yok" demektir, Windows'taki davranışın testi değildir.

$ python3 drive_denetim.py yol 'G:\My Drive\isler\gorsel.png'
Yol: G:\My Drive\isler\gorsel.png
  Bu makinede var mı: HAYIR
  Drive sanal sürücüsü olası: evet
    - yol parçası 'my drive' içeriyor
    - G: Drive for desktop'ın varsayılan sürücü harfi (değiştirilebilir)
  Yerel araç: Yerel araçlar açabilir AMA şartlar: Drive for desktop çalışıyor, oturum açık; akış modunda dosya çevrimdışı değilse internet gerekir (ilk açılışta indirilir). Video, büyük ZIP, rastgele okuma ve çok küçük dosya yükünde SSD'den yavaş/kırılgan olabilir.
  Web AI: Bir web sohbeti (ChatGPT/Claude/Gemini/Grok) bu yolu kendiliğinden açamaz: yol yalnız dosyanın bulunduğu makinenin dosya sisteminde anlamlıdır. Web/bulut AI dosyaya ancak şu yollarla ulaşır: (1) dosyayı sohbete yüklemek, (2) servisin Google Drive bağlayıcısı — OAuth, yalnız senin Drive izinlerin kadar, (3) bu makinede çalışan ve o klasöre izin verilmiş bir yerel ajan/köprü (masaüstü uygulaması, yerel MCP dosya sunucusu vb.), (4) herkese açık link — ancak servis linki açabiliyorsa. Yerel araçlar (Cursor, Claude Code CLI/Desktop, Python, ComfyUI) kendi izin/sandbox ayarları elverdiği sürece bu yolu doğrudan açabilir.
