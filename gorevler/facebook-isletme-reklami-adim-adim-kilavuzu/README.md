# Facebook işletme reklamı – adım adım kılavuz

Bir işletmenin Facebook (Meta) üzerinden sıfırdan reklam açıp yayına almasını anlatan Türkçe
kılavuz. Ekranın farklı çıktığı durumlar için alternatif yollar da kılavuzda. Meta'nın resmi
Türkçe yardım sayfalarıyla **3 Ekim 2026**'da doğrulandı.

| Dosya | Ne |
|---|---|
| **[KILAVUZ.md](KILAVUZ.md)** | Ana kılavuz: buradan başla |
| [KILAVUZ.html](KILAVUZ.html) | Aynı kılavuz, tek dosya. Telefonda ya da bilgisayarda çevrimdışı açılır |
| [KILAVUZ.pdf](KILAVUZ.pdf) | Yazdırılabilir A4 sürüm |
| [harita.md](harita.md) | Hedef → bağımlılıklar → A/B/C yolları → uygulama → test → teslim haritası |
| [kaynaklar.md](kaynaklar.md) | Resmi Meta kaynakları, topluluk deneyimleri ve araç karşılaştırması (tam HTTPS bağlantılar) |
| [kabul-dogrulamasi.md](kabul-dogrulamasi.md) | Kabul maddeleri, kanıtlar ve yapılamayanlar |
| [kabul-raporu-otomatik.md](kabul-raporu-otomatik.md) | `dogrula.py` çıktısı |
| [calisma-gunlugu.md](calisma-gunlugu.md) | Çalışma günlüğü |
| `araclar/dogrula.py` | Bağlantı ve resmi içerik doğrulayıcı |
| `araclar/derle.py` | MD'den HTML ve PDF üretici |

**Kısa yol:** Bilgisayardan business.facebook.com → Sayfa ve reklam hesabı → ödeme →
adsmanager.facebook.com → **+ Oluştur** → amaç → reklam seti → reklam → **Yayınla**.
Ayrıntılar ve "ekran farklıysa" dalları KILAVUZ'da.
