# Komik Foto Paketleri — X tarzı absürt Türkiye fotoğrafları, dörtlü karışık

## İçerik
- `foto/` — **48 gerçek fotoğraf** (esnaf/tekel tabelaları, apartman notları, uyarı yazıları, absürt kareler, haber ve X kaynaklı) + `foto/kaynaklar.csv` (her biri için kaynak sayfa, varsa X gönderisi, görsel URL, SHA-256).
- `paketler/paket-01 … paket-12/` — her biri 4 fotoğraf:
  - `instagram/1-4.jpg` (1080×1350, karusel)
  - `tiktok/1-4.jpg` (1080×1920, Foto modu)
  - `tiktok-reels-onizleme-sessiz.mp4` (10 sn; müziği uygulamada ekle)
  - `PAYLASIM.txt` → slayt sırası, **şarkı**, Instagram ve TikTok açıklaması, etiketler
- `index.html` — tüm paketlerin çevrimdışı önizlemesi (tarayıcıda aç).
- `arastirma/` — müzik listesi (kanıt linkli), açıklama örnekleri (birebir), kaynaklar ve platform kuralları, harita.
- `YAYINLAMA-REHBERI.md` — telefondan paylaşma adımları.
