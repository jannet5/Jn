# How to Build Real Mobile Apps with Claude - FULL COURSE
# https://www.youtube.com/watch?v=lpeP6BcUlFU

In this complete build, we're vibe coding a full-stack Flight Booking Mobile App (Flightly) with an Admin Dashboard from scratch using AI! ✈️ 

You’ll learn how to build production-grade mobile applications with dynamic seat selection, real-time booking management, CMS administration, and seamless database architecture.

🚀 What We're Building & What You'll Learn:
• Full-stack Mobile App built with Expo & React Native
• Sanity.io CMS Admin Panel for airlines, routes, and flight schedules
• Supabase for user authentication, bookings, and seat inventory
• AI-powered coding workflow with Claude Code & Whisper Flow
• Interactive Aircraft Seat Selection & Real-Time Seat Locking
• Search, filters (Cheapest, Fastest, Best), and checkout flows

🛠️ Tech Stack:
- Frontend: Expo (React Native), Expo Router
- Admin CMS: Sanity.io (GROQ queries)
- Backend & Auth: Supabase (PostgreSQL, Row-Level Security)
- AI Coding Tools: Claude Code / Cursor / Whisper Flow
