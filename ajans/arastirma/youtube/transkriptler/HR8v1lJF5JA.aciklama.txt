🚀 In this video, I showcase a complete AI-powered Social Media Automation System built with n8n.

This workflow uses multiple AI agents working together to automate the entire content creation and publishing process for Facebook, Instagram, and LinkedIn.

✅ What this system does:

🔹 Accepts a post topic from the user
🔹 AI generates the post description/caption
🔹 AI creates an engaging post title
🔹 AI generates a professional image prompt
🔹 Pollinations AI automatically creates the post image
🔹 Uploads the generated image
🔹 Publishes content automatically to social media platforms
🔹 Sends Slack notifications after successful publishing

🧠 AI Agents Used:
• Description Generator Agent
• Image Prompt Generator Agent
• Title Generator Agent
• Image Generation Agent

⚙️ Tech Stack:
• n8n
• OpenAI
• Pollinations AI
• Slack
• Facebook Automation
• Instagram Automation
• LinkedIn Automation
