Full Website Prompt 
Create a modern, clean, and visually appealing restaurant website design inspired by a burger landing page.
Use a warm yellow/orange color scheme with food-focused visuals and bold typography.
One file should be HTML and the second file should be CSS.
Include:
Header with logo, navigation menu, and contact info
Hero section with large burger image, bold heading (e.g., “Burger Week”), price badge, and CTA
Featured items / popular burgers section with image cards
“Choose & Enjoy” section with 3 product cards and buttons
Upcoming events section with image and description
Reservation / booking form section (Book Your Table)
Promotional banner or discount section
Footer with contact details and social icons

Design should be image-heavy, with soft shadows, clean spacing, modern card layout, and attractive UI similar to a fast-food landing page.
Make it fully responsive and suitable for HTML & CSS implementation.
