How to use Claude Design. Claude Design lets you create slide decks, documents, social graphics, and even clickable website mockups that all match your brand. In this video, I will walk you through it from your very first prompt to a finished, on-brand presentation, even if you have never touched a design tool before.
 
Claude Design is built right into Claude, and after some big recent upgrades it has way more templates and much more efficient usage, which makes it genuinely useful for beginners. We start with a plain prompt and a simple flyer, then look at the questions Claude asks before it builds anything, because that step is the difference between a generic result and a good one. From there we build a real design system using a logo and a couple of images, so every design that follows comes out on brand automatically. We use it to make a clickable website mockup, a full pitch deck from a markdown file of talking points, and an invoice, and I show you all four ways to edit your work. At the end we cover exporting to PowerPoint, PDF, Canva, and standalone HTML, plus how to hand a mockup over to Claude Code when you want to build the real thing.
