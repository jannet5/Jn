Impeccable is the free Claude Code design skill that stops AI slop. I install it and rebuild a real funnel page with it on camera (64.6K stars on GitHub).

Purple gradient, three cards, the same font. Every site AI builds looks the same until you give it taste. Impeccable is one command, four questions, then "visual worlds" to pick from. After that you click any element and tell it what to change.

📦 THE REPO
Impeccable (free, open source, 64.6K stars) → https://github.com/pbakaus/impeccable
Docs and all 23 commands → https://impeccable.style

⚡ THE COMMANDS IN ORDER
1. npx impeccable install   (in the terminal, inside your project folder)
2. claude                   (start Claude Code)
3. /impeccable              (writes PRODUCT.md + DESIGN.md, asks you 4 questions)
4. pick a visual world      (it opens in the browser — choose one, re-roll if you don't like it)
5. live                     (click any element, comment on it, it fixes just that part)
6. /impeccable animate ...  (motion on the section you name)
