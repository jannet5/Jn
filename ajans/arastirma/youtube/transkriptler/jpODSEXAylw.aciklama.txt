# Claude Code End-to-End: Building and Deploying a Real Project from Scratch

In this video, I'm developing a real project from scratch for those who want to learn Claude Code. First, we explain Claude Code's interface, model and effort settings, and the Skill and Connector system. Then, we create our own Skill and develop a tour booking site with Next.js; we complete the backend, admin panel, GitHub, automated testing, and deployment phases step by step. At the end of the project, we perform automated testing with TestSprite, let Claude use the browser with Claude in Chrome, and deploy the project live for free via Vercel + Render. 🎁 🤝 TestSprite offers 150 credits free per month. If you want to try it: https://www.testsprite.com/?via=ugur (advertisement) 🎁 I also address the following questions in the video: Can Claude Code be used without knowing how to code? Which model and effort setting is more logical? When does the context expire and what does Compact do? Is using bypass permissions safe? How far can a real project be taken with Claude Code?
